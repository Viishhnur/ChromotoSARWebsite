# 🌍 Chromoto SAR – AI-Powered Remote Sensing for Disaster Management

Chromoto SAR is an AI-driven web platform leveraging **Generative AI and Remote Sensing** for **SAR (Synthetic Aperture Radar) image colorization, flood detection, and crop mapping**. It enables real-time SAR data processing for **environmental monitoring, disaster management, and agriculture**.

## 🚀 Features

✅ **SAR Image Colorization** – Converts grayscale SAR images into realistic colorized representations.  
✅ **Flood Detection** – Identifies flood-affected areas using AI-driven analysis.  
✅ **Crop Mapping** – Maps SAR crop images to ground truth images for agricultural insights.  
✅ **Scalable Cloud Architecture** – Powered by **AWS EC2** and **Docker** for real-time processing.  
✅ **User-Friendly Interface** – Built with **React.js** for smooth interaction and visualization.

## 🛠️ Tech Stack

- **Frontend**: React.js(Website), Tailwind CSS , Flutter(App)
- **Backend**: Flask, Node.js, Express.js
- **Database**: Firebase , MongoDB
- **Cloud & Deployment**: AWS EC2, Docker
- **Machine Learning**: PyTorch, (for SAR image processing)

## 📌 Installation Guide

### 1️⃣ Clone the Repository

```sh
git clone https://github.com/Viishhnur/ChromotoSARWebsite.git
cd Chromoto-SAR
```

2️⃣ Install Dependencies

```sh
npm install  # For frontend and backend
```

3️⃣ Run the Application

```sh
#Frontend
npm start

#Backend
cd backend
node index.js
```

4️⃣ Open in Browser
Visit: http://localhost:3000 🚀
